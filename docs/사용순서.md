# AI Seller OS — 상품 하나를 파는 전체 순서

> 헷갈릴 때 이 문서를 보세요. 지금 어디에 있고 다음이 무엇인지만 적었습니다.

---

## 0단계 — 처음 한 번만 (아직 안 하셨으면 여기부터)

이건 앱이 대신 못 합니다. **판매자 계정이 없으면 상품을 올릴 곳 자체가 없습니다.**

| 할 일 | 어디서 |
|---|---|
| 사업자등록 | 홈택스 |
| 통신판매업 신고 | 정부24 |
| 판매자 계정 개설 | 각 마켓 판매자센터 |

**한 마켓부터 하세요.** 심사에 며칠 걸리고, 5곳을 동시에 열면 주문·CS·발주가 한꺼번에 밀려옵니다.

그리고 앱에서 한 번만:

```
설정 → 내 판매자 정보
   A/S 책임자·연락처   ← 내가 받는 번호. 도매처 번호 절대 금지
   품질보증기준        ← 기본 문구가 이미 들어 있음
```

이걸 적어두면 **모든 상품의 고시정보에 자동으로 채워집니다.**

---

## 1단계 — 소싱: 무엇을 팔지 고르기

```
소싱센터
```

**① 도매꾹에서 검색하거나 카테고리를 엽니다**
**② 확장 → 🔎 검색 목록에서 후보 한꺼번에 담기 → 이 화면의 상품 담기 → 후보 복사**
**③ 앱 소싱센터에 붙여넣고 [분석하기]**

여기서 걸러집니다 — 묶음판매 / 배송비 과다 / 단가 과소 / 인증규제 / 옵션 과다.
살아남은 것이 **추천순**으로 나옵니다.

> 붙여넣는 순간 **오늘의 스냅샷**으로도 저장됩니다. 내일 같은 검색어로 담으면
> 🛰️ 레이더가 "어제 없던 것 / 도매가 내린 것"을 보여줍니다.

**④ 📊 소매 시세와 맞대보기 → 조사 목록 복사 → 확장에서 시세 조사 → 결과 반영**

여기서 대부분이 떨어집니다. **도매가 싸도 소매가 이미 더 싸면 팔 수 없습니다.**

**⑤ 🟢 남은 것에서 [＋ 상품으로 담기]**

---

## 2단계 — 상품 채우기

```
상품 → 그 상품
```

지금은 목록에서 읽은 **이름·공급가·배송비만** 들어와 있습니다. 나머지를 채웁니다.

**① 도매처 상품페이지를 엽니다**
**② 확장 → 📋 복사 (앱에 붙여넣기)**
**③ 상품 화면의 「📋 확장에서 수집한 내용 붙여넣기」에 붙여넣고 [내용 확인]**

무엇이 바뀌는지 표로 보여줍니다. 맞으면 **[이 내용으로 채우기]**.
→ 옵션·스펙·최소구매수량·도매처 반품정책이 채워집니다.

**④ 판매가를 정합니다** (소싱센터에서 본 시세를 보고)

판매가가 들어가면 손익·옵션별 손익·등록 검토가 나타납니다.

**⑤ [상세페이지 만들러 가기 →]**

---

## 3단계 — 등록센터: 검토 → 승인 → 마켓별

```
① 검토  ›  ② 내가 승인  ›  ③ 마켓에 올리기
```

### ① 검토 — 프로그램이 확인합니다

판매가 · 옵션 손익 · 배송비(선불) · 고시정보 · 반품정책 · 상세페이지.
**🔴가 있으면 승인 버튼이 잠깁니다.** 대개 여기서 막힙니다:

| 막히는 이유 | 어떻게 |
|---|---|
| **고시정보 부족** | 「상품정보 제공고시」 카드를 열어 빈 칸을 채웁니다. 재질·크기·구성품은 도매처 페이지에 있습니다 |
| 역마진 옵션 | 그 옵션을 끄거나 판매가를 올립니다 |
| 판매가 없음 | 2단계 ④로 |

### ② 내가 승인 — 사람만 볼 수 있는 2가지

```
□ 이 이미지를 써도 됩니까?          ← 사용 허용 표기 + 로고·연락처 없음
□ 원본에 없는 효능을 넣지 않았습니까?
```

**둘 다 체크해야 [✅ 이 상품 등록 승인]이 눌립니다.**
승인 후 판매가를 바꾸면 승인이 자동으로 풀립니다.

### ③ 마켓에 올리기 — 승인해야 열립니다

여기가 **네이버에 올리는 부분**입니다. 마켓을 고르면 그 마켓에 맞춘 카드가 나옵니다.

```
① [판매자센터 ↗]  → 그 마켓 상품등록 화면이 열립니다
② [📋 등록정보 전체 복사] → 메모장에 붙여두고 보면서 채웁니다
     상품명 / 판매가 / 배송비(선불) / 옵션 / 고시정보 / 반품안내
③ 상세설명 칸을 HTML 모드로 바꾸고
   [상세페이지 HTML 복사] → 붙여넣기 → 일반 모드로 복귀
④ 회색 칸 4곳을 지우고 그 자리에 이미지 업로드
     확장 → ⬇️ 선택한 이미지 다운로드 (다운로드 > AISOS > 상품명)
⑤ 마켓에서 등록 완료
⑥ 앱으로 돌아와 [올렸음 ✓]     ← 안 누르면 「오늘 할 일」에 계속 남습니다
```

**두 번째 마켓부터는 훨씬 빠릅니다:**

| | 다시 해야 하나 |
|---|---|
| 상세페이지 HTML | ❌ **5곳이 완전히 같습니다.** 복사해둔 걸 그대로 |
| 상품명·가격·옵션 | ⭕ 마켓마다 [복사] (길이 제한이 달라 앱이 맞춰줍니다) |
| **이미지** | ⭕ **마켓마다 다시 업로드** (각 마켓 서버에 올라가야 합니다) |

---

## 4단계 — 올린 뒤

```
오늘 할 일
```

- **🛡️ 공급가·재고 감시** — 확장으로 여러 상품을 한 번에 점검. 공급가가 오르면 손해가 시작됩니다
- **💰 공급가가 내려갔습니다** — 이미 파는 상품에서 마진이 늘어난 것
- **주문 가져오기** → 발주 전 최종검사 → 발주 → 송장 → 정산

## 「자동 등록」은 지금 어디까지인가

**솔직하게: 마켓에 올리는 마지막 한 걸음은 아직 손으로 합니다.**

| 단계 | 지금 |
|---|---|
| 도매 목록 담기 | **자동** (확장 버튼 1번) |
| 1차 거르기 | **자동** (계산) |
| 소매 시세 조사 | **자동** (탭이 열렸다 닫힘) |
| 가격 자리 판정 | **자동** (계산) |
| 상세 수집 | **반자동** (복사 → 붙여넣기) |
| 상세페이지 글 | **자동 생성** |
| 고시정보 | **반자동** (도매처에서 읽히는 건 자동, 나머지만 입력) |
| 마켓별 변환 | **자동** |
| **마켓에 입력** | 🔴 **수동** |
| 이미지 업로드 | 🔴 **수동** |

**왜 아직 수동인가**

마켓 오픈API는 존재하지만 **API 키를 브라우저에 둘 수 없습니다.** 서버가 있어야 하고,
사업자 인증과 마켓별 승인도 따로 받아야 합니다.

**어떻게 줄일 것인가 (계획)**

```
Phase 2  엑셀 대량등록 파일 생성   ← 파일 하나로 50개. 서버·승인 불필요
Phase 3  확장으로 판매자센터 폼 자동 채우기
Phase 4  오픈API (백엔드 필요)     ← 상품 10~30개 운영해본 뒤
```

**Phase 3을 위해 필요한 것이 하나 있습니다.** 판매자센터 등록 화면은 로그인해야 열려서
제가 볼 수 없습니다. 계정을 만드신 뒤:

```
네이버 스마트스토어 → 상품등록 화면을 열고
확장 → 🧭 판매자센터 등록화면 살펴보기 → [이 화면의 입력칸 읽기] → [결과 복사]
```

이걸 주시면 **[자동으로 채우기]** 버튼을 만들 수 있습니다.
입력도 저장도 하지 않고 **칸 이름만** 읽습니다.

## 한 장 요약

```
0  계정 만들기 · 설정에 내 판매자 정보          ← 처음 한 번
1  소싱센터: 담기 → 분석 → 시세 → ＋상품으로 담기
2  상품: 확장 수집 붙여넣기 → 판매가 정하기
3  등록센터: 검토 → 승인 → 마켓별 복사 → 마켓에서 등록 → 올렸음 ✓
4  오늘 할 일: 감시 · 주문 · 발주 · 송장 · 정산
```
