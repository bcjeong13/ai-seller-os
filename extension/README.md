# AI Seller OS 수집기 (크롬 확장)

알리익스프레스 / 1688 / 타오바오 상품 페이지에서 **상품명·가격·옵션·특징**을 수집해
AI Seller OS 앱으로 보내는 크롬 확장입니다.

## 설치 (개발자 모드 — 최초 1회)

1. 크롬 주소창에 `chrome://extensions` 입력 후 이동
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** 클릭
4. 이 `extension` 폴더 선택
5. 툴바에 퍼즐(🧩) 아이콘 → "AI Seller OS 수집기" 고정(📌)

## 사용법

1. 알리/1688에서 **팔고 싶은 상품 1개의 상세페이지**를 엽니다. (검색 목록 화면 ❌ — 상품을 클릭해 들어간 화면 ⭕)
2. 페이지에서 **옵션·색상·사이즈·재질 등 특징 부분을 마우스로 드래그(선택)** 합니다.
3. 툴바의 **AI Seller OS 수집기 아이콘**을 클릭합니다.
   - 상품명·가격·URL이 자동으로 채워지고, 드래그한 내용이 "옵션·특징"에 담깁니다.
4. 값을 확인/수정한 뒤 **📋 복사** 를 누릅니다.
5. AI Seller OS 앱 → **상품 추가 → "📥 크롬 확장에서 가져오기"** 칸에 **붙여넣기(Ctrl+V)** → **가져오기**.
   - 상품명·통화·가격·배송비·옵션·특징이 자동으로 채워집니다.

## 중요 안내

- **⚠️ 가격은 "정상가"로.** 알리의 "신규회원/할인 전용가"는 1회성이라, 소싱 원가는 정상가로 넣어야 손실을 막습니다. (앱에도 경고가 표시됩니다)
- 배송비는 페이지 표시값을 직접 입력하세요("무료 배송"이면 0).
- 사이트 구조가 바뀌면 자동 수집이 일부만 될 수 있어요. 그때는 팝업에서 값을 직접 고치면 됩니다.
- 이 확장은 **여러분이 보고 있는 페이지의 공개 정보만** 읽습니다. 로그인 정보나 다른 사이트에는 접근하지 않습니다.
