# AI Seller OS 수집기 (크롬 확장)

국내 도매 사이트(도매꾹·도매매·오너클랜 등) 상품 페이지에서
**상품명·공급가·옵션·특징·상세 이미지**를 수집해 AI Seller OS 앱으로 보내는 크롬 확장입니다.

## 설치 (개발자 모드 — 최초 1회)

**폴더 경로:** `C:\Users\User\ai-seller-os\extension`

### 엣지(Edge)

1. 주소창에 `edge://extensions` 입력 후 Enter
2. **왼쪽 아래** "개발자 모드" 스위치 켜기
3. **압축을 푼 항목 로드** 클릭
4. 위 `extension` 폴더 선택 → **폴더 선택**
5. 툴바 퍼즐(🧩) 아이콘 → "AI Seller OS 수집기" 옆 **눈 모양(👁)** 클릭해 고정

### 크롬(Chrome)

1. 주소창에 `chrome://extensions`
2. **오른쪽 위** "개발자 모드" 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. `extension` 폴더 선택
5. 퍼즐(🧩) → 📌 고정

> 초록색 ⬇ 아이콘이 툴바에 보이면 설치 완료입니다.

### 코드를 고친 뒤에는

확장 관리 화면에서 이 확장의 **새로고침(↻)** 버튼만 누르면 반영됩니다. 재설치 불필요.

### "이 사이트의 모든 데이터를 읽고 변경" 경고가 뜹니다

정상입니다. 어느 도매 사이트를 쓸지 미리 알 수 없어서 전체 주소를 허용받습니다.
실제로는 **여러분이 아이콘을 누른 그 탭 한 개만** 읽습니다. 데이터를 외부로 보내지 않습니다.

## 사용법

1. 도매 사이트에서 **팔고 싶은 상품 1개의 상세페이지**를 엽니다.
   (검색 목록 화면 ❌ — 상품을 클릭해 들어간 화면 ⭕)
2. 툴바의 **AI Seller OS 수집기 아이콘**을 클릭합니다. 그게 전부입니다.

**도매꾹에서 자동으로 채워지는 것**

| 항목 | 어떻게 |
|---|---|
| 상품명 | 페이지 제목 (`[도매꾹]` 접두어 자동 제거) |
| 공급가 | 페이지 내부 판매단가 값 |
| 배송비 | "N개까지 X원" 구간의 첫 금액 |
| 옵션 | 옵션 데이터를 통째로 — **추가금(±)까지 포함** |
| 스펙 | 원산지·모델명·제조사·부피/무게·재고 |
| 반품정책 | 반품/교환정보 원문 (반품배송비 포함) |
| 이미지 | 200×200px 이상 상세 이미지 전부 |

접혀 있어서 화면에 안 보이는 **배송조건·반품정책 영역까지** 읽습니다.
직접 드래그해서 선택한 텍스트가 있으면 그것도 함께 담습니다. (선택사항)

다른 사이트에서는 사이트 구조가 달라 일부만 채워질 수 있습니다.
팝업 상단에 **무엇을 가져왔는지** 표시되니, 빈 칸만 직접 채우면 됩니다.

### 이미지 다운로드

수집된 이미지는 기본적으로 전부 선택되어 있습니다. **필요 없는 것을 클릭해 해제**하세요.

**빼야 할 이미지**
- 공급사 로고·상호가 박힌 것
- 공급사 연락처·카톡ID가 있는 것
- "도매 문의" 같은 B2B용 배너
- 다른 상품 홍보 배너

**⬇️ 선택한 이미지 다운로드** 클릭 →
`다운로드 폴더 > AISOS > [상품명] > 상품명_01.jpg, _02.jpg …` 순서대로 저장됩니다.

이 파일들을 각 마켓(쿠팡 WING, 스마트스토어센터 등) 상품 등록 화면에 직접 업로드하세요.

### 앱으로 보내기

4. 값을 확인/수정한 뒤 **📋 복사** 를 누릅니다.
5. AI Seller OS 앱 → **상품 추가 → 📥 도매처에서 상품 가져오기** 칸에 **붙여넣기(Ctrl+V)** → **가져오기**
   - 상품명·공급가·배송비·도매처·옵션·스펙·반품정책이 자동으로 채워집니다

> **반품정책은 도매처가 셀러에게 주는 조건입니다.** 고객에게 그대로 약속하는 정책이 아닙니다.
> 앱에서 별도로 확인·승인해야 상세페이지에 들어갑니다.

## 중요 안내

- **⚠️ 수량별 단가에 주의.** 도매는 구매 수량에 따라 단가가 다릅니다.
  **내가 실제로 살 수량의 단가**를 넣어야 손실을 막을 수 있습니다.
- **배송비를 꼭 확인하세요.** 국내 소싱에서 마진을 가장 많이 먹는 항목입니다.
  도매처가 나에게 청구하는 금액을 넣으세요 (무료면 0).
- **이미지 사용 권한은 공급사마다 다릅니다.** 상품페이지에 "이미지 사용 가능" 표기가 있는지
  확인하고, 없으면 공급사에 문의하세요. 확장은 수집만 할 뿐 권한을 판단하지 않습니다.
- 200×200px 미만 이미지는 아이콘으로 보고 자동 제외합니다.
- 사이트 구조가 바뀌면 자동 수집이 일부만 될 수 있어요. 그때는 팝업에서 값을 직접 고치면 됩니다.
- 이 확장은 **여러분이 보고 있는 페이지의 정보만** 읽습니다. 다른 탭이나 사이트에는 접근하지 않습니다.
