# AI Seller OS — 국내 도매 소싱 손실방어 도구

국내 도매(도매꾹 등)에서 소싱해 **쿠팡·네이버·11번가·G마켓·옥션**에 파는 셀러를 위한
**주문 순간 손실방어** 도구입니다. 백엔드·데이터베이스 설치가 필요 없고, 브라우저에서 바로 돌아갑니다.

> 📖 **처음이라면 [매뉴얼.md](매뉴얼.md)를 먼저 보세요.** 소싱부터 마켓 등록까지 전체 흐름이 순서대로 정리되어 있습니다.

## 🚀 실행

### 가장 쉬운 방법
`시작하기.bat` 더블클릭. 처음 한 번은 설치가 진행되고, 이후 브라우저가 자동으로 열립니다.

### 명령어로 실행
```bash
npm install   # 최초 1회만
npm run dev   # 앱 실행 (http://localhost:5173)
```

## 🧭 핵심 화면

1. 처음 열면 상단의 **"데모 데이터 불러오기"** 로 예시를 확인하세요.
2. **대시보드** — 손실/위험/품절/채널 반영 필요 상품을 한눈에.
3. **상품 추가** — 도매 공급가와 배송비만 넣으면 예상 순이익이 실시간 계산됩니다.
   목표 마진을 정하면 **권장 판매가를 역산**해 줍니다.
4. **상품 상세**
   - **🛒 고객 주문 (발주 검증)** = 핵심 기능. `ORDER_PREFLIGHT_CHECK` 11개 항목을 검사해
     **손실이면 발주를 자동 차단**하고 승인 대기로 전환합니다.
   - **손익 시뮬레이터** — 값을 바꾸면 순이익이 즉시 바뀌고, "적용"하면 저장됩니다.
   - **공급처 상태** — 품절로 바꾸면 발주가 차단됩니다.
   - **원가 변동 / 이벤트 로그 / 주문 스냅샷** 확인.
5. **상세페이지** — 상품명 후보·키워드·태그·고지문 **텍스트**를 생성합니다.
   (이미지는 크롬 확장으로 받아 마켓 에디터에 직접 업로드)

## ✅ 검증된 핵심 로직 (자동 테스트 40개 통과)

```bash
npm test
```

- 손익 계산(공급가·배송비·수수료 반영), 손익분기, 권장 판매가 역산
- 이상 가격 감지
- **ORDER_PREFLIGHT — 시나리오 A(공급가 인상)·B(품절)·C(배송비 급등)·D(데이터 노후)**
- 상세페이지 생성 규칙, 확장 가져오기 파서

## 🧩 크롬 확장 (상품·이미지 수집기)

`extension/` 폴더를 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드"로 설치.

- 도매 상품 페이지에서 **상품명·공급가·스펙·상세 이미지**를 자동 수집
- 이미지를 썸네일로 보여주고, **체크한 것만 일괄 다운로드**
  (`다운로드 > AISOS > 상품명 > 상품명_01.jpg …`)
- **📋 복사** → 앱의 "상품 추가 → 가져오기"에 붙여넣기

자세한 사용법은 [extension/README.md](extension/README.md) 참고.

## 📦 이 앱이 지키는 원칙

- **SELLER_INVENTORY ≠ SUPPLIER_STOCK** (위탁배송 = 셀러 재고 0)
- **PREFLIGHT 없이 자동 발주 금지**
- 모든 금액은 **결정론적 코드**로 계산 (LLM 미사용)
- 주문 시점 손익 **스냅샷 영구 보존**
- 데이터가 오래되면 **추측 대신 재확인 요구**

## ⚠️ 범위 밖

- **해외 소싱(중국 등)** — 관세·환율·통관 로직은 제거되었습니다. 국내 소싱 전용입니다.
- **세무 판단** — 부가세 계산은 포함되어 있지 않으며, 실제 신고는 세무사 확인이 필요합니다.
- **이미지 사용 권한** — 공급사마다 다릅니다. 앱은 확인 여부를 체크·경고할 뿐 판단하지 않습니다.
