# AI Seller OS — Phase 0 (무재고 구매대행 손실방어 코어)

1688 무재고 구매대행 셀러를 위한 **주문 순간 손실방어** 도구입니다.
백엔드·데이터베이스 설치가 필요 없고, 브라우저에서 바로 돌아갑니다.

## 🚀 실행 방법 (초보자용)

### 가장 쉬운 방법
`시작하기.bat` 파일을 **더블클릭**하세요. 처음 한 번은 설치가 진행되고, 이후 브라우저가 자동으로 열립니다.

### 명령어로 실행
```bash
npm install   # 최초 1회만
npm run dev    # 앱 실행 (http://localhost:5173)
```

## 🧭 사용법

1. 처음 열면 상단의 **"데모 데이터 불러오기"** 를 눌러 예시 상품들을 확인하세요.
2. **대시보드** — 손실/위험/품절 상품을 한눈에.
3. **상품 추가** — 판매가·1688 원가만 넣으면 예상 순이익이 실시간 계산됩니다.
4. **상품 상세**
   - **🛒 고객 주문 (발주 검증)** = 핵심 기능. 주문이 들어왔다고 가정하고 `ORDER_PREFLIGHT_CHECK` 13개 항목을 검사해, **손실이면 발주를 자동 차단**하고 승인 대기로 전환합니다.
   - **손익 시뮬레이터** — 값을 바꾸면 순이익이 즉시 바뀌고, "적용"하면 저장됩니다.
   - **공급처 상태** — 품절로 바꾸면 발주가 차단됩니다.
   - **원가 변동 / 이벤트 로그 / 주문 스냅샷** 확인.

## ✅ 검증된 핵심 로직 (자동 테스트 20개 통과)

```bash
npm test
```

- 손익 계산(수수료·환율·배송비 반영), 손익분기, 구매대행 수수료
- 관부가세 $150(물품가격) 분기
- 이상 가격 감지
- **ORDER_PREFLIGHT — 시나리오 A(가격급등)·B(품절)·C(배송비급등)·D(데이터노후)**

## 📦 이 앱이 지키는 원칙 (프롬프트 v3 기준)

- **SELLER_INVENTORY ≠ SUPPLIER_STOCK** (구매대행 = 셀러 재고 0)
- **PREFLIGHT 없이 자동 발주 금지**
- 모든 금액은 **결정론적 코드**로 계산 (LLM 미사용)
- 주문 시점 손익 **스냅샷 영구 보존**
- 데이터가 오래되면 **추측 대신 재확인 요구**
